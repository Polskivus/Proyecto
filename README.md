Este es un progama a modo de demo, en el que gestionamos las piezas y los empleados de una compañia, hemos implementado PANDAS para que la lectura de CSV y edicion del mismo sea mas facil.

Luego al finalizar lo guarda todo en una sqlite, para que al momento de que se cree la base de datos definitiva se pueda volcar toda la informacion.

Necesario descargar PANDAS para el uso de esta aplicacción, aparte de importar SQLite3 para la creacion de las tablas

Hemos investigado como hacer el remoto la progamacion y utilizariamos google colab, no nosha dado tiempo de implementarlo, pero creemos que seria una de las mejores maneras de trabajar en remoto.
