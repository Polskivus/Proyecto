
README — Proyecto DAM (Programación + Lenguaje de Marcas).

Este proyecto de 1º DAM tiene dos partes: una parte de programación en Python para gestionar piezas y empleados usando ficheros CSV y una base de datos SQLite, y una parte de Lenguaje de Marcas con varias páginas web hechas con HTML, CSS y JavaScript, incluyendo elementos interactivos.

Estructura del proyecto: en la parte de Python hay varios archivos. El archivo menuPrincipal.py es el “centro” del programa por consola: muestra un menú principal y, según la opción, permite ver piezas, añadir piezas, buscar o editar una pieza por id, borrar piezas por id, o entrar en el módulo de trabajadores. Dentro del módulo de trabajadores hay un submenú con opciones para listar empleados, ver un empleado por DNI, añadir, editar, eliminar, y guardar cambios antes de volver al menú principal.

El módulo piezasdb.py contiene la lógica para trabajar con las piezas. Define una función para conectarse a SQLite y varias funciones que trabajan principalmente sobre un CSV: insertar una pieza añade una nueva fila calculando un id nuevo, mostrar piezas carga el CSV y devuelve el DataFrame, buscar por id permite editar el nombre y opcionalmente la cantidad, eliminar piezas borra la fila correspondiente, y cargarcsvadb vuelca el CSV completo a una tabla de SQLite. Además incluye una función para resolver rutas de archivos de forma compatible con ejecución normal o empaquetado.

El módulo empleadosdb.py gestiona empleados usando Pandas. Carga empleados desde un CSV en un DataFrame, permite buscar por DNI devolviendo una fila, muestra empleados por consola, lista todos los empleados, añade un empleado validando que el DNI no exista, edita campos permitiendo dejar valores por defecto si se pulsa Enter, elimina un empleado y guarda los cambios en el CSV, y también tiene una función que guarda el DataFrame en SQLite usando to_sql. Igual que el módulo de piezas, utiliza una función de rutas de recursos pensada para que el proyecto funcione aunque se empaquete.

El archivo inicializardb.py sirve para inicializar la base de datos una sola vez. Crea la tabla de piezas (piezascoche) con id, nombre y cantidad, y la tabla de empleados (empleados) con DNI como clave primaria y los campos edad, nombre y puesto. El archivo users.py es una versión preliminar anterior del módulo de empleados basada en lectura y escritura de un TXT con una lista de diccionarios, y no corresponde con la versión final que usa CSV/SQLite.  

Parte de Lenguaje de Marcas: hay varias páginas HTML. La página index.html actúa como portada, con un menú superior y tarjetas informativas del proyecto, y desde ahí se organiza el acceso a las demás secciones. La página personalizador.html implementa un personalizador de coche dibujando en un canvas: el usuario puede elegir el tipo de alerón, el tipo de ruedas y cambiar colores con selectores e inputs de color; cada cambio dispara un redibujado del canvas para reflejar la configuración seleccionada. La página cuello-botella.html crea una escena con varias “piezas” y una pared animada; incluye un control deslizante para modificar la velocidad de la pared mediante una variable CSS, y un script que comprueba colisiones calculando rectángulos de posición y deteniendo la animación cuando una pieza colisiona. La página FAQ.html contiene una sección de preguntas frecuentes con comportamiento tipo acordeón: al hacer click en una pregunta se muestra su respuesta y se cierran las demás. El archivo styles.css define los estilos de la animación y la variable global que controla la velocidad de la pared en la escena
